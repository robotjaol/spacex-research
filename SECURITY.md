# Security and research-use scope

This repository provides offline educational simulations. It has no hardware control interface, operational telemetry connection or flight qualification. Do not connect its output to a physical vehicle or treat its models as operational design approval.

For a vulnerability in this repository, use the destination repository's private vulnerability reporting facility if enabled. Do not post credentials or private system details in a public issue. If private reporting is not available, contact the repository owner through an established private channel before sharing sensitive details. No response-time commitment is made.

Numerical/model defects normally belong in a reproducible bug report. Suspected vulnerabilities in SpaceX, NASA or an upstream dependency belong with that organization's own reporting process; this project cannot receive or authorize testing on their behalf.

Only public, permissioned material is accepted. The repository does not solicit leaked software, restricted technical data or access to operational systems.
