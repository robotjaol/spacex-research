# Licensing decisions

The initial repository uses MIT for original code, prose, diagrams and generated synthetic records. This keeps the scope simple and permits reuse with the required notice. The license does not apply to linked documents, upstream dependencies, trademarks or patented inventions.

Alternative future choices include Apache-2.0 for original software when an express patent-license provision is desired, and CC-BY-4.0 for separately scoped prose. These are optional policy choices, not simultaneously applied licenses. Changing the license later requires respect for contributor rights and already-distributed versions.

Dependencies are installed independently and are not bundled. Direct tested packages include NumPy/SciPy under BSD-style terms and Matplotlib under its own permissive license agreement. Their distributions can contain additional third-party notices. The source catalogue records the license evidence reviewed for optional tools, including Hypatia's component-specific MIT/GPL split.

The Falcon guide's copyright notice restricts reproduction. Other publicly accessible guides, papers and patent documents are not presumed open-licensed. The repository therefore provides links and original short summaries, without source PDFs, screenshots, copied diagrams, code excerpts or proprietary design files. This is a project distribution policy, not a legal opinion about every possible use.
