# Technical references

Start with the [source catalogue](../references/source-catalogue.md), [paper index](../papers/paper-index.md), [claim ledger](../references/claims.json) and [evidence gaps](../references/gaps.md). The catalogue distinguishes official system descriptions, academic methods and upstream software.

Use a source for the claim it can support. A patent establishes a disclosed concept; a regulatory order establishes an authorization scope; a simulation paper establishes behavior under a stated model. None alone establishes an operational SpaceX implementation.
